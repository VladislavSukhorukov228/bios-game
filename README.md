# БИОС — публикация на GitHub Pages

Игра — статический сайт. Сервер, npm и ключи API не нужны.

1. Создайте публичный репозиторий, например bios-life. Это сохранит старую игру bios3 отдельно.
2. Распакуйте BIOS-GitHub-Pages.zip. Загрузите содержимое архива в корень репозитория: index.html, все .js, style.css и папку assets целиком. Не загружайте сам ZIP вместо файлов.
3. Нажмите Commit changes.
4. В Settings → Pages выберите Deploy from a branch, затем main и /(root), нажмите Save.
5. Дождитесь завершения публикации. Адрес появится в Settings → Pages.

Для обновлений заменяйте файлы с сохранением структуры папок. Все пути в игре относительные.
Прогресс хранится в браузере: сохранение с другого домена автоматически не переносится.
Музыка запускается сразу, если разрешено браузером, либо при первом касании.
Озвучка включается отдельно в диалогах. Доступные голоса зависят от устройства; можно назначить их персонажам в разделе «Голоса персонажей».

Официальная инструкция:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
